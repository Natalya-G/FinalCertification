## Итоговая аттестация

Данная работа может быть использвана в качестве фреймворка для тестирования API и UI.

### Автотесты написаны с использванием:
- Java
- Maven
- jUnit5
- RestAssured
- JDBC
- Selenide
- Allure

### Инструкция по запуску автотестов:
1. Открыть командную строку
2. Перейти в папку проекта 
3. Для запуска автотестов выполните команду - mvn clean test
4. Для просмотра Allure отчета выполните команду - allure serve
Примечание: На машине должны быть установлены Maven и Allure

### Инстркукция по запуску автотестов через GitHub Actions:
1. Открыть проект в GitHub - https://github.com/Natalya-G/FinalCertification
2. Откройте вклдаку "Actions"
3. В разделе run-test выполните действия:
   - нажать на "Run workflow"
   - выберите ветку для запуска (по умолчанию main)
   - нажать на "Run workflow"
4. Для просмотра отчета откройте раздел pages-build-deployment
5. Откройте последний прогон
6. Откройте ссылку, которая указана в блоке deploy
